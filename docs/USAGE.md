# 网站、检测与流量设置

## 伪装网站

在「系统设置 → 伪装网站」启用，选择内置模板或上传根目录含 index.html 的静态 ZIP，再保存。公开域名应反代到公开服务（默认 127.0.0.1:8081）。访问 `https://公开域名/` 查看网站；`https://公开域名/s/令牌` 获取订阅。管理服务默认 8080，应使用独立受保护入口。

关闭网站后根路径返回 404，订阅与 ACME 验证继续工作。Hysteria2 可在普通创建中勾选网站回落；网站启用时才允许该回落。关闭网站前先关闭相关入口的回落。REALITY 使用握手目标，不会回落到本地网站。静态网站不执行 JavaScript 或表单。

## 协议可用性检测

在「协议入口」点击检测图标，弹窗内开始检测。检查当前生效配置、启用用户、入口连接，并用临时 Mihomo 客户端保留真实地址、端口、认证、SNI 和 TLS 校验发起 204 请求。不重载服务进程，也没有直连回退。检测使用少量真实网络流量，计入服务器用量。

结果分为可用、未通过、尚不能判断。配置或进程在检测期间变化时要求重测；原生监听器因自行管理客户端参数，暂不自动进行完整协议检测。自签证书未被客户端信任时会失败，不会自动跳过校验。服务器侧通过不能保证外部网络到 VPS 的端口可达；仍需在实际客户端测试。

流程参考 [3m-ui 的隔离客户端检测思路](https://github.com/kazeyukiro/3m-ui/blob/main/backend/internal/mihomo/connection_check.go)，使用本项目的配置导出和进程管理实现。

## 服务器流量

「系统设置 → 服务器流量」配置：

- 每月上限以 GiB 输入，0 表示不限；1 GiB = 1024³ 字节。上限用于展示和提醒，不会自动停用代理。
- 重置日为每月 1–31 日的 00:00，按所选时区执行；没有该日期的月份使用月末。更改日期或时区可能开启新周期。
- 自动使用 Linux 默认 IPv4 路由的网卡，也可指定 eth0、ens3 等接口。IPv6-only 环境请显式指定网卡。
- 双向统计发送和接收；仅出站只计网卡发送的数据。按 VPS 服务商计费方向选择。

网卡累计独立于代理协议连接采样，包含该网卡上的其他服务。每 5 秒保存，面板与订阅读取时也会刷新。从首次监控开始记录，无法反查启用前的历史用量，也不包含服务商链路层计费差异。正常进程重启延续持久化基线；主机重启和网卡计数归零继续累计。周期边界没有观测的间隙不跨周期追算，停机与边界可能有少量漏计。流量记录不包含在配置备份内。

直接安装或 Docker host 网络可读取所在网络命名空间的网卡；Docker bridge 只能统计容器接口。Windows 不支持 /proc，面板会显示不可用。读取失败时保留最近记录，不把旧数据标为当前。

有效订阅的 YAML 与分享链接响应均返回：

```text
Subscription-Userinfo: upload=123; download=456; total=1073741824
X-PrismFlow-Traffic-Reset-At: 1795132800
X-PrismFlow-Traffic-Status: current
```

单位均为字节；所有用户展示同一份服务器周期用量。仅出站模式中 download=0。total=0 表示未设上限。重置时间使用独立的 Unix 秒 Header；不填 expire，因为周期重置不是订阅到期。客户端是否展示额外的重置字段取决于其实现。采集不可用时 Status 为 unavailable，用量为最后可读记录。

## 订阅和表单

订阅详情使用弹窗，节点名格式为「用户名 · 入口名」。重置订阅链接只撤销旧 URL；重置用户凭据同时更换 UUID/密码，Shadowsocks 共享入口密码除外。两项均有页面内确认框。

输入框提供示例。字段旁问号可展开详细说明；说明不会覆盖输入。按 Escape 先收起当前帮助，再按一次关闭所在弹窗。
