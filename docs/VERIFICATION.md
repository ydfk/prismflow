## 2026-10-31 自定义 HTTPS 端口与多选快速创建

统一 HTTPS 地址支持显式端口，新建反代 XHTTP 的公网端口从统一地址继承，未显式设置时前后端行为一致；已有协议仅在勾选同步时变更反代公网端口，直连协议监听端口保留。非默认端口在管理/订阅 URL、来源校验、部署检查和生成的 Caddy/Nginx 配置中保留。

快速创建改为 1–4 个预设多选，提供全选/清空和选中数量。单选可转为普通创建，多选禁用并说明原因；根据所选组合显示 REALITY、XHTTP 专用设置和共享证书。混选反代 XHTTP 与 AnyTLS/Hysteria2 时不会清空后两者的证书，所有入口在同一事务创建，任一冲突整批拒绝。

Go 测试覆盖四协议混选、共享证书、8443/10443 默认值、订阅分享链接和反代端口、失败批次无部分保存，以及显式同步只更新反代端口。TypeScript/Vite 与 Go 构建、go vet 通过。浏览器回归新增非默认端口从快速创建转普通创建、混合 TLS 批量保存并实际应用内核、订阅和反代配置保留 8443，以及桌面/手机多选布局。证书 CA 验证端口要求另按 HTTP-01/DNS-01 处理，未因此改写协议握手目标的 443。

本轮没有修改 VPS 反代、端口、防火墙或环境变量，未发布新 Tag 或镜像；实际 VPS 的 8443/10443 公网可达性需部署后使用检查功能验证。
